# Base EVM Smart Contract Security Auditor

An AI-driven security scanner for Solidity smart contracts deployed on the **Base** Layer-2 and EVM-compatible blockchains.

## Features
- Real-time detection of critical Web3 vulnerabilities (Reentrancy, Unprotected functions, Phishing vectors, Low-level calls).
- Remediation recommendations mapped to OpenZeppelin best practices.
- Multi-chain EVM support (Base, Ethereum, Arbitrum, Optimism).
- Zero-Solana compliance.
